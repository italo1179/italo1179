## Sobre mim

Sou estudante de **Engenharia de Software** e estou no início da minha jornada na programação.

Atualmente, estou construindo minha base com **lógica de programação e linguagem C**. Uso este perfil para registrar os exercícios que desenvolvo durante os estudos, acompanhar minha evolução e aprender com os erros e melhorias de cada projeto.

Também utilizo **inteligência artificial como ferramenta de desenvolvimento**. Com ela, consigo transformar ideias em protótipos, explicar o que preciso, orientar mudanças, testar funcionalidades, encontrar problemas e melhorar o resultado por meio de várias iterações. Alguns dos meus projetos web foram feitos nesse formato de **vibe coding** e estão identificados claramente neste perfil.

Ainda tenho muito a aprender. Meu objetivo agora não é parecer um desenvolvedor experiente, mas praticar com constância, entender bem os fundamentos e escrever códigos cada vez mais organizados.

### O que estou praticando

- Entrada e saída de dados
- Variáveis e operadores
- Estruturas condicionais
- Laços de repetição
- Vetores e strings
- Funções e parâmetros
- Ponteiros em exercícios básicos
- Algoritmos simples e resolução de problemas
- Git e GitHub para publicar minha evolução
- Criação de prompts e especificação de funcionalidades para IA
- Teste, revisão e refinamento de código gerado por IA
